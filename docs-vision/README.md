claude.ai; the PDFs and Word files are the same content for sending by email.

## Notes

- Figures in doc 06 are illustrative ranges, not a forecast — the assumptions
  are on the page so they can be flexed.
- The HTML files are self-contained (fonts from Google Fonts, no other
  dependencies). Open directly in a browser, or print to PDF.
- Canonical live versions are the claude.ai artifacts; these repo copies exist
  so the work survives independently of any one account or session.
